# 🟡 Pac-Man with Hand Gestures 🎮✋

Control **Pac-Man using your hand gestures** instead of a keyboard!  
This project uses **computer vision** to detect hand movements through a webcam and translates them into real-time in-game controls.

> No keyboard. No controller. Just your hand. 🖐️

---

## 🚀 Features

- 🎥 Real-time hand gesture detection using webcam  
- 🟡 Classic Pac-Man gameplay  
- ✋ Gesture-based movement  
  - Move hand **left / right / up / down** to control Pac-Man  
- 🧠 Smooth and responsive controls  
- 💻 Beginner-friendly and easy to run  

---

## 🛠️ Tech Stack

## ⚙️ Installation

1. Clone the repository:
```bash
git clone https://github.com/your-username/pacman-hand-gestures.git
```

2. Navigate to the project folder:
```bash
cd pacman-hand-gestures
```

3. Install dependencies:
```bash
pip install opencv-python mediapipe pygame
```

---

## ▶️ How to Run

```bash
python main.py
```

Make sure your **webcam is connected and allowed**.

---

## 🖐️ Controls (Hand Gestures)

| Gesture Direction | Action |
|------------------|--------|
| Thumbs Up          | Move Up |
| Thumbs Down        | Move Down |
| Peace sign        | Move Left |
| Open Palm       | Move Right |
